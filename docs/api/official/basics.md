## 概述

批量计算作业平台是应对海量批处理作业的分布式作业任务管理平台。可支持海量作业并发，系统智能的对任意规模批处理作业进行资源分配、作业调度和任务管理。广泛应用于电影动画渲染、生物数据分析、多媒体转码、科学计算、人工智能等领域。

## 请求状态码（业务码）

**请求状态码**

| 状态码 | 错误码 | 状态信息 | 描述 |
| --- | --- | --- | --- |
| 400 | BC_0001 | InvalidArgument | 请求参数无效，这可能是由于参数缺失、格式错误或者超出了有效范围。 |
| 400 | BC_0002 | AlreadyExists | 表⽰请求的资源已经存在。这可能是由于试图创建⼀个已经存在的资源。 |
| 400 | BC_0003 | PermissionDenied | 表⽰没有执⾏操作的权限。这可能是由于⾝份验证失败、访问被拒绝或者没有⾜够的权限执⾏操作。 |
| 400 | BC_0004 | FailedPrecondition | 表示请求能够正常执行的服务端状态和当前服务端的状态不一致，例如，应用实例正在删掉中，请求再一次请求删除实例。 |
| 400 | BC_0005 | Unauthenticated | 表示请求端的用户没有权限，当前情况需要检查是否登录信息已经过期，重新刷新页面。 |
| 400 | BC_0006 | Internal | 表示请求端的请求发送到服务端，服务端发生了内部处理错误。 |
| 400 | BC_0007 | ResourceExhausted | 表示请求的资源已经耗尽或者售罄。 |
| 400 | BC_0008 | NotFound | 表示请求的资源或者方法不存在。 |
